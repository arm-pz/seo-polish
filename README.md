# seo-polish

Audit SEO health with Seo-Audit, then generate optimized alternatives with Wordsmith. Use when the user wants a full technical + on-page SEO diagnosis followed by concrete rewrite alternatives for titles, meta descriptions, headings, content gaps, and internal linking — and wants both the audit findings and polished fixes.

## Usage

```text
/seo-polish https://example.com
/seo-polish [paste page content]
Audit my site's SEO and give me fixes.
```

## Workflow

1. **Seo-Audit** performs comprehensive technical + on-page SEO diagnosis
2. **Wordsmith** generates polished alternatives for High/Medium findings
3. Returns executive summary + alternatives + recommended actions

## Dependencies

Requires `seo-audit` and `wordsmith` skills to be installed.
